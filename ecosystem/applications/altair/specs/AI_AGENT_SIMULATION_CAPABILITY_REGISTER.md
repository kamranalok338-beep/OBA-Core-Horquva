# AI Agent and Simulation Capability Register

**Status:** No capability approved or implemented
**Owner:** Gul Daraz - AI Agent & Simulation Engineering
**Roadmap:** Part 2, Steps 7 and 8

No approved agent or simulation scenario is available in the repository yet, so
this register does not claim that a prototype exists.

## Entry required for each capability

| Item | What to record |
| --- | --- |
| Purpose and users | The engineering problem and the people allowed to use it |
| Inputs and boundaries | Approved data, tools, permissions, and what the capability cannot access |
| Output | What it returns, who receives it, and whether it is a suggestion or simulation |
| Version | Agent, model, prompt, tool, or simulation configuration version |
| Test evidence | Scenarios, evaluation method, results, and reviewer |
| Limits | Known failure modes, unsupported cases, and safety concerns |
| Human oversight | The person or platform that reviews the result and owns the decision |
| Security | Sensitive-data handling and access considerations |

A capability can be added to this register only after its scope, test plan, and
human-review path are agreed. It remains a prototype until its results are
reviewed and approved.
